# Лабораторные работы по DevOps

Учебный проект для изучения Git, GitHub и практик DevOps. В лабораторной работе №0 настраивается рабочее окружение и отрабатывается полный цикл изменения проекта: отдельная ветка, коммит, Pull Request и слияние в основную ветку.

## План изучения DevOps

1. Освоить Git: коммиты, ветки, удалённые репозитории и разрешение конфликтов.
2. Научиться работать с GitHub: Pull Request, обсуждение и проверка изменений.
3. Изучить командную строку и основы администрирования Linux.
4. Освоить контейнеризацию приложений и управление их окружением.
5. Научиться автоматизировать сборку, тестирование и доставку приложений.
6. Познакомиться с инфраструктурой как кодом, мониторингом и журналированием.

План будет уточняться по заданиям следующих лабораторных работ.
